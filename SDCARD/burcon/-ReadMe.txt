Burcon CP/M 2.2 for the Altair 8800

The file "cpm48k.dsk" and "cpm56k.dsk" are bootable Burcon CP/M 2.2 disks
sized for 48K and 56K of RAM, respectively. Run MOVCPM to size for a
different amount of RAM.

See the "ReadMe.pdf" file up two levels in the "CPM" folder for more
information about Burcon CP/M.
